# Security Policy

## Reporting a Vulnerability

Si encuentras una vulnerabilidad, repórtala por mensaje privado al dueño del
repo (marcojpad-hash). No abras un issue público con los detalles.

## Scope

Este repo no guarda credenciales: las claves y tokens viven fuera del repo
(en el entorno local). Si un secreto aparece commiteado por accidente, se
revoca y se elimina del historial.
