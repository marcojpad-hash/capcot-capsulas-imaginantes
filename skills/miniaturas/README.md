# Skill: miniaturas — portadas de YouTube

Los archivos canónicos de esta skill viven fuera de esta carpeta y NO se
duplican aquí. Esta carpeta es el apuntador.

## Archivos canónicos

- **Skill (borrador vigente):** `docs/SKILL_youtube_portada_thumbnail.md`.
- **Regla de miniatura (lección 2026-11-22):** YouTube elige sola un frame
  de en medio si no se sube miniatura personalizada. Cada subida lleva su
  primer frame como miniatura personalizada (el montaje guarda el frame 0
  como `miniatura.png` en el paquete) y se verifica la miniatura real tras
  subir (`i.ytimg.com/vi/<id>/hqdefault.jpg`), no solo el video.
- **Excepción canal EN y Kids:** YouTube exige verificar un número de
  teléfono para miniaturas personalizadas; mientras no esté verificada, las
  subidas quedan programadas con miniatura automática y se les pone la
  personalizada después, ANTES de que se publiquen.
