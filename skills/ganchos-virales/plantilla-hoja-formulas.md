# Plantilla — Hoja de fórmulas (desglose viral)

Una fila por video estudiado. Una hoja por idioma (ES y EN por separado:
no se traducen las fórmulas, se traduce la estructura).

| Columna | Qué va |
|---|---|
| URL del video | Enlace al Short / TikTok / Reel |
| Plataforma | YouTube Shorts / TikTok / Reels |
| Idioma | ES / EN |
| Vistas | Vistas del video al estudiarlo |
| Mediana del canal | Mediana de vistas del canal (SortViral la da) |
| Outlier | Vistas ÷ mediana (guardar solo ≥5×, mejor 10×) |
| Fecha de publicación | Para filtrar últimos 90 días |
| Duración | Segundos |
| Gancho (literal, primeros 3 s) | La frase exacta con la que abre |
| Tipo de gancho | Interrupción / afirmación fuerte / hueco de curiosidad / corrección / historia / controversia |
| Refuerzo (3–7 s) | Segunda promesa o subida de apuesta |
| Micro-ganchos | Cada loop de retención y su posición |
| Estructura de valor | Historia / paso a paso / mito-corrección / comparación / lista |
| Payoff (timestamp) | En qué segundo exacto cae el payoff |
| CTA | Qué pide y dónde |
| Primer frame | Qué se ve en el frame 0 (lo visual también es gancho) |
| Texto en pantalla (3 s) | Qué dice el texto inicial |
| Cortes | Frecuencia de cortes / cambio visual |
| Fórmula (rellenable) | [Gancho] → [Refuerzo] → [Valor] → [Micro-gancho] → [Más valor] → [Prueba] → [CTA] → [Cierre] |
| Por qué funcionó | 2–3 frases |

## Regla de síntesis

Al cerrar una tanda (5–10 videos por idioma), solo se queda en la fórmula
del equipo lo que aparece en **al menos 3 videos**. Lo que aparece una sola
vez se descarta: puede ser suerte, timing o audiencia, no estructura.
